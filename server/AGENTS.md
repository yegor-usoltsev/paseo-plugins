# Resume scheduling

The plugin targets the installed Paseo SDK. Always send with `activeTurnBehavior: "steer"`; a turn can start after the idle check. Parent notices use `sourceAgentId` so Paseo renders native sender identity.

Hook contexts provide the host SDK. Restored jobs use a scoped connection to the TCP address in `$PASEO_HOME/paseo.pid` and that home's local credential, never a guessed port. Run limit and lifecycle tests in both UTC and Europe/Minsk after reset-time changes.

A pending entry's object identity invalidates asynchronous work after cancellation or a new limit. Every await before sending or changing a job needs that check. A send can return after the resumed turn already scheduled its next retry. Busy agents keep their jobs; only the turn started by this plugin inherits its parent notice.
